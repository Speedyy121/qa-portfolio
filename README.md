# 🎮 Szymon Kochanowski - QA Portfolio

Welcome to the repository of my personal portfolio website! 

I am a dedicated **Functionality Quality Assurance (FQA) Tester** with commercial experience (officially credited in *MOUSE: P.I. For Hire*). This website serves as a central hub for my resume, testing methodologies, and my upcoming transition into QA Automation.

🔗 **Live Website:** [Here](https://skqa.vercel.app/)

## 🛠️ Built With
This project was built with a focus on clean, responsive, and lightweight frontend technologies:
*   **HTML5** (Semantic structure and multi-page routing)
*   **Tailwind CSS** (Utility-first CSS framework for styling via CDN)
*   **AOS (Animate On Scroll)** (For smooth scroll animations)

## ✨ Features
*   **Bilingual Support:** Fully translated content (English / Polish) accessible via intuitive navigation.
*   **Responsive Design:** Mobile-first approach ensuring perfect layout on desktops, tablets, and smartphones.
*   **Dark Theme:** A modern, tech-oriented dark mode fitting the gaming and QA industry.
*   **Zero-Dependency Setup:** No package manager (npm/yarn) required. Ready to run directly in the browser.

## 🚀 How to Run Locally
Since this is a static site built without a complex build pipeline, running it locally is incredibly simple:
1. Clone the repository: `git clone https://github.com/szymon-kochanowski/qa-portfolio.git`
2. Navigate to the project folder.
3. Open `index.html` or `index_pl.html` in any modern web browser.
